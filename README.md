# Tosh Otar

Brauzerda ishlaydigan arkada o'yin: zambarakni suring, raqamli toshlarni sindiring, tanga yig'ib kuchaying.

**O'ynash:** `index.html` faylini brauzerda oching — hech narsa o'rnatish shart emas.

## Qanday o'ynaladi
- Zambarak o'zi otadi — siz faqat uni chapga-o'ngga surasiz.
- Toshdagi raqam — uni sindirish uchun kerak bo'lgan zarbalar soni.
- Katta tosh sinsa, ikkita kichik toshga bo'linadi.
- Tosh zambarakka tegsa — o'yin tugaydi.
- Singan toshlardan tanga tushadi. Menyuda tangalarga **Tezlik** (o'q/soniya) va **Kuch** (zarba)ni oshiring.
- Har 5-darajada — katta **boss** tosh. Har 3 darajada fon almashadi: kunduz → shom → tun.

## Boshqaruv
- **Telefonda:** barmoqni ekranda chapga-o'ngga suring
- **Kompyuterda:** sichqoncha yoki ← → / A D
- **P / Esc** — pauza, **M** — ovoz

Daraja, tangalar va kuchaytirishlar brauzerda saqlanadi.

## 📱 iPhone'ga o'rnatish
Sahifani **Safari**'da oching → **Ulashish** → **"Bosh ekranga qo'shish"**. O'yin bosh ekranda o'z belgisi bilan to'liq ekranda ochiladi.
